# 创意简报：友链页「Epheia」特别模块设计

> 请你以**资深前端工程师 + 视觉设计师**的身份，先完整读完以下背景与约束，再给出创意。目标不是写代码，而是提出比现有方案更好、更独特的设计方向。

---

## 一、项目背景

- **项目名**：curve-react —— 博客主题「curve」的 React 重制版
- **技术栈**：React 18 + TypeScript + Vite 5 + Tailwind CSS 3.4；图标库 `lucide-react`；路由 `react-router-dom`
- **站点**：Sy's Digital Garden（404yann.com），个人博客
- **本次页面**：友情链接页 `/links`
- **交付形态**：最终实现为一个 React + Tailwind 组件，嵌入友链页；优先纯 CSS 动画 + 内联 SVG，**不希望引入重依赖**（如 three.js），除非创意确实需要且收益明显

## 二、必须遵守的设计系统

主题概念是「**报纸版 Newspaper edition**」：**纸张是品牌，字体是声音，颜色只有一枚印章红。**

### 设计令牌（HSL 分量，Tailwind 中以 `hsl(var(--token))` 使用）

| 令牌 | 亮色（明室） | 暗色（暗房） | 含义 |
|---|---|---|---|
| `--paper` | 43 42% 90% | 0 0% 9% | 页面底色（旧报纸米白 / 中性深灰） |
| `--paper-warm` | 39 38% 86% | 0 0% 14% | 暖纸 / 抬升面 |
| `--paper-soft` | 44 40% 93% | 0 0% 11% | 卡片浅底 |
| `--ink` | 28 12% 9% | 40 16% 91% | 主文字（暖墨黑 / 暖白） |
| `--ink-strong` | 28 16% 5% | 40 18% 96% | 标题 |
| `--ink-body` | 28 12% 17% | 40 11% 85% | 正文 |
| `--ink-muted` | 28 9% 31% | 38 8% 66% | 次要文字 |
| `--ink-faded` | 28 7% 43% | 38 6% 52% | 弱化文字 |
| `--rule` | 28 14% 14% | 0 0% 32% | 分隔线（深） |
| `--rule-soft` | 28 9% 28% | 0 0% 24% | 分隔线（浅） |
| `--stamp` | **5 68% 36%** | **42 55% 58%** | 印章红（暗色下转为琥珀金） |
| `--stamp-soft` | 5 60% 92% | 42 40% 20% | 印章色的浅底 |

此外站点还会按一天中的时间（黎明 / 黄昏 / 深夜）微调令牌（`data-time-theme`），所以任何新颜色都应从上述令牌派生，不要凭空发明新 hex。

### 字体

- **展示标题 / 正文**：Noto Serif SC（中文衬线，宋体感）
- **UI**：Inter / Noto Sans SC（无衬线，仅用于导航、按钮）
- **标签 / 日期 / 编号**：JetBrains Mono（等宽，仅用于短拉丁字符）
- **圆角极小**：2–4px（报纸不怎么用圆角）
- **暗色模式概念**：「暗房显影」——像在暗房冲洗照片，或黑胶唱片套内；中性深灰底 + 暖白文字 + 琥珀金点缀

## 三、现有友链页长什么样（基线，用来做对比）

- 页面标题「友情链接」，副标「与各位博主无限进步」，有一个「随机访问」按钮
- 内容按分组（如「本站」「小伙伴们」），每组有组标题 + 站点数
- 每个友链是**统一网格卡片**：左侧圆形头像，右侧名字 + 一句话描述；hover 时整卡变成印章红底、文字变纸色
- 现有友链示例：池鱼小栈「｜д•´)!!」、Clover Yan「生命是灰色的，理论之树常青。」、纸月 Paper Moon「マジやばくね」等

**关键要求：新模块要和这些统一卡片在视觉与交互上明显拉开，让人第一眼就感到「这个位置是特别的」，但又不能脱离整站的纸张 / 墨 / 印章设计语言。**

## 五、硬性约束

1. 模块为她**单独存在**，不进入普通友链网格；位置在友链页分组区域附近（全宽特别栏目）
2. 独特、新颖，但与站点设计系统自洽：纸张 / 暖墨 / 一枚印章色、衬线排印、克制的用色
3. **亮色与暗色主题下都成立**；响应式，桌面与手机都有良好布局
4. 整个模块可点击，新标签页打开 https://me.epheia.moe/
5. 可访问性：语义化 `<a>`、合适的 `aria-label`、键盘 `focus-visible` 样式、支持 `prefers-reduced-motion`
6. **不使用 emoji**；图标用内联 SVG
7. 三个信息字段必须保留：名字 Epheia、描述「今天也有在好好记得你」、地址 me.epheia.moe

## 六、已经存在的一版方案（请评价，并提出**不同方向**，不要只做微调）

方案名：**「一盏灯 · 记得」**

- 友链页中单独开一个「特别栏目」，模块是一块**深墨色整幅面板**（亮色模式下也像夜晚亮着灯的窗），报纸专栏式的双层细线边框
- 左侧场景：一支 CSS 绘制的白蜡烛，火苗用内联 SVG + 摇曳动画，周围有缓慢呼吸的暖光晕；旁边是她的头像，做成红图钉固定、微倾斜的拍立得小照，hover 时摆正
- 右侧文字：等宽小标签 REMEMBERING、大字衬线名字 Epheia、主标语「今天也有在好好记得你」
- 一个**活着的计数器**：「今天是记得你的第 N 天」，以 2026-07-24 为起点按天计算，跨天自动 +1；下方显示起算日与今天的中文日期
- 右上角一枚朱红方印「记得」（暗色下变琥珀金）；hover 面板时火苗变亮、光晕扩大、显现「me.epheia.moe ↗」

请先评价这版方案：**它的优点、可能的问题**（例如：烛火 / 纪念意象是否过于直白甚至俗套？深黑面板在亮色页面里是否突兀？计数器是否合适、会不会有伦理或情感上的不妥？交互是否只是"好看"而缺乏与"记得"主题的深层呼应？）
