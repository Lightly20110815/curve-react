# 曲線時報 v4 修改与复审

[当前 HTML](../preview-home-v4.html)已经重写。只修改自己的预览文件夹；项目源码和其他代理的文件没有编辑。

固定高度的黑色头条块和贯穿长页的侧栏已取消。文章使用连续的日期、标题、简介排版；《过期的存档点》的真实照片保留在自己的文章位置。主标题固定按“她不只是 / 一个用户名”两行阅读，语义块在首次打开时依次落定，约 1.34 秒后静止，没有循环、碎裂或反弹。“重播标题”这个演示控件也已删掉。

音乐只有一个持续的控制面。播放条随阅读保留，17 首曲库按需打开；窄屏打开曲库时，播放进度移动到曲库中，复用原来的控件。打开真实文章后，同一个音频继续播放。预览内嵌了所有专辑封面和文章照片，无须加载中文网络字体或前端依赖。音频使用仓库已有 MP3。

| 复审方向 | 最终结论 |
| --- | --- |
| Anthropic 品牌相似度 | 通过。粗黑刊名、真实目录与播放条形成个人刊物语气；删除演示控件后，没有足以判为 AI 拼装的强证据。 |
| AI 模板感与视觉工艺 | 通过。日期、标题、摘要共享阅读次序，照片属于具体文章，手机没有重新堆成独立模块。 |
| 艺术指导与文字动效 | 可展示预览，没有必须修的问题。动作承担语义重音与停顿，不强行绑定旁边歌曲，也不建议增加装置。 |

以上是三位代理看过实际截图后的判断，没有数字评分，也不替代用户对审美的判断。

浏览器验证结果：

- 320、390、768、1024、1440px 五个宽度均无页面横向溢出，“一个用户名”没有裁切。390px 宽的手机上，完整标题位于约 271—378px；标题、简介和阅读入口均在首屏。
- 曲库切换至 `Ceremony` 后实际播放，媒体无错误、封面加载成功；打开文章后播放时间继续递增，始终只有一个 audio 元素。暂停、返回目录、搜索 `DeepSeek` 也已实际操作。
- 模拟 6、12、18、23 时，深浅两套主题均进入正确的四个时段，并应用对应底色。减少动态模式下动画数为 0，标题直接完整显示。
- 320 × 740 的曲库高度修正后，面板底部位于 724px，曲库内部可滚动；播放进度只有一份。打开文章时，播放栏准确停在视口顶部。
- HTML 没有重复 ID，脚本语法检查通过，浏览器未报页面错误。尚未把此预览接入 React 源码，也没有做 Windows / Android 实机字体检查。
